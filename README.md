# ドロップリネーマー

ドロップリネーマーは、送り先フォルダーの名前と連番を使って、ファイル名を整理するWindows用の小型アプリです。

ファイルをアプリへドラッグ＆ドロップし、送り先フォルダーを選び、変更内容を確認してから処理を実行します。

## 変更例

送り先フォルダーが `旅行写真` の場合：

```text
旅行写真_001.jpg
旅行写真_002.jpg
旅行写真_003.png
```

## 主な機能

- ファイルをドラッグ＆ドロップで追加
- 送り先フォルダーをツリーから選択
- ファイル名を変更しながらコピーまたは移動
- 元のフォルダーと送り先が同じ場合は、その場所でリネーム
- 元の名前、新しい名前、場所、処理状態を実行前に一覧表示
- 同じフォルダーでリネームする行をオレンジ色で表示
- 同名ファイルがある場合は、空いている連番まで自動で進める
- 選択した項目だけを一覧から削除
- 前回の送り先フォルダーと処理方法を記憶
- ウィンドウの位置、サイズ、4列の幅の比率と並び順を記憶
- 保存したウィンドウ位置が画面外になった場合は、見える位置へ戻す
- ファイルごとに処理結果やエラーを表示

アプリ内にファイル選択ボタンはありません。処理対象のファイルは、必ずドラッグ＆ドロップで渡します。

## 動作環境

- Windows 10 または Windows 11
- 64ビット版Windows（x64）

## 使い方

1. ドロップリネーマーを起動します。
2. 処理したいファイルをウィンドウへドラッグ＆ドロップします。
3. 送り先フォルダーを選びます。
4. 「コピー」または「移動」を選びます。
5. 新しいファイル名と場所を確認します。
6. 処理を実行します。

大切なファイルを大量に処理する前に、コピーしたテスト用ファイルで動作を確認してください。

## ソースコードからのビルド

必要な環境：

- .NET 10 SDK
- Windows、またはWPFをビルドできる環境

```powershell
dotnet build DropRenamer.sln
```

ソースコードから実行：

```powershell
dotnet run --project .\src\DropRenamer\DropRenamer.csproj
```

.NET 10ランタイムを同梱したWindows x64用の単一EXEを作成：

```powershell
dotnet publish .\src\DropRenamer\DropRenamer.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -p:DebugType=None -p:DebugSymbols=false -p:Version=1.0.0
```
